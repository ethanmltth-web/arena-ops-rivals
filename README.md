# Arena Ops — Rivals Manager

Browser-based esports franchise manager. **Roblox Rivals** is playable now; Valorant and Rocket League are stubbed for later.

## Play

Open with any static server, or via XAMPP:

`http://localhost/web%20game/`

Or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features (Rivals)

- Found an org and enter the **Rivals Pro League** (8 teams, 14-week season)
- **Randomly generated** players with aim, movement, mechanics, game sense, teamwork, morale, energy
- **Signature stars** (premium cost): Swift, SlingshotBwai, VortexRLX
- Free agency sign / release, weekly payroll, match prizes
- Training facility (aim lab, movement, mechanics, VOD, team scrims, recovery)
- Match day best-of-3 sim with tactics
- Standings, schedule, finances, local save/continue
